# 導入事例

サービスサイトの中核。検討中の読み手が**自分に近い事例を探しに来る**ページ。
コーポレートサイトではなく、サービスサイト側に置く。

---

## このセクションに書くこと

| 要素 | 必須 | 中身 |
|---|---|---|
| 変化した数字 | ◎ | 導入前 → 導入後。「3日からゼロへ」「1か月から9日へ」 |
| 業種 | ◎ | 読み手が自分と重ねるための第一条件 |
| 規模 | ◎ | 従業員数・拠点数。「21〜50名」「全国150事業所」 |
| 何に困っていたか | ◎ | 導入前の状態を具体的な作業で書く |
| 決め手 | ○ | なぜそれを選んだか |
| 顧客の言葉 | ○ | 発言をそのまま引用する |

**業種と規模を必ず添える。** これがないと、読み手は自分に当てはまるか判断できない。

---

## タイトルの型

導入事例のタイトルは、**検索でも一覧でも機能する**必要がある。3つの型がある。

### 型A：数字の変化 ＋ 成功要因
```
「（作業）を（前）から（後）へ。（規模）の（顧客の言葉）が（成果）の鍵」
```
> 給与明細配付を3日からゼロへ。2.8万人の「現場が使いやすい」が労務DX成功の鍵
> ——[SmartHR 導入事例](https://smarthr.jp/case/)

### 型B：数字の変化 ＋ 前の状態からの脱却
```
「（作業）が（前）から（後）に短縮。（旧来のやり方）から脱却」
```
> 勤怠集計が3日から1日に短縮。ハンコと紙の非効率・属人性から脱却
> ——[freee 導入事例](https://www.freee.co.jp/cases/)

### 型C：規模の制約 ＋ それでも実現したこと
```
「（不利な条件）でも（成果）。（規模）の（現場）に（浸透率）」
```
> 全国150事業所の年末調整が1か月から9日へ。社用端末なしの現場にも9割浸透
> ——[SmartHR 導入事例](https://smarthr.jp/case/)

## 事例

### SmartHR（[導入事例](https://smarthr.jp/case/)）

> 全従業員に想いを届ける。社内報の閲覧数が16倍！人的資本経営に寄与する「お知らせ機能」活用

> 脱・情報管理の属人化とハンコリレー。SmartHRへの移行で業務負担を約60%削減

> 交替勤務でもすれ違わない。思い立ったらすぐ連絡できるメッセージ機能がもたらす負荷軽減と安心感

> 勤怠も給与も、SmartHRへ。多様な勤務形態でも給与計算を社内で完結

**効いている点**
- **1タイトルに「変化」と「機能名」の両方が入っている。** 機能名（お知らせ機能、メッセージ機能）は検索語であり、同時に「どの機能の話か」の索引にもなる。
- 「ハンコリレー」「すれ違わない」など、**現場の言葉をそのまま使っている**。「業務効率化」と書くより状況が見える。
- 体言止め＋句点で前半を切り、後半で内容を説明する2部構成。一覧で並んだときに視線が止まる。

### freee（[導入事例](https://www.freee.co.jp/cases/)）

> 転記作業を削減し、業務量を7割削減 製造・飲食・EC、70人の多角化経営を1人で支えるバックオフィス
> ——有限会社上手工作所（製造業・メーカー、51〜100名）

> 集計時間は3分の1へ。工場350名の勤怠締めがICカードとfreeeで「実質1日」に縮小
> ——株式会社アサヒコ（製造業・メーカー、301〜500名）

> 人事労務工数、70％削減。北海道の管工事・冷設会社が挑む暗黙知から「学ぶ組織」への変革
> ——札幌中野冷機株式会社（不動産・建築・建設業、21〜50名）

**効いている点**
- **全事例にカテゴリ（業種）と従業員数レンジが併記されている。** これがサービスサイトの導入事例で最も重要な設計。読み手は業種と規模で自分に近い事例を選ぶ。
- 「北海道の管工事・冷設会社」と地域と業態を具体名で書いている。「地方企業」ではない。
- 「実質1日」「1人で支える」と、**制約条件を数字で書いている**。成果だけでなく、どんな体制でそれをやったかが伝わる。

## 本文の型

```
1. 会社紹介（1段落）：何をしている会社か、規模
2. 課題（1〜2段落）：導入前に何にどれだけ時間がかかっていたか
3. 検討（1段落）：何を比較し、何が決め手だったか
4. 導入（1段落）：どう進めたか、どこでつまずいたか
5. 成果（1〜2段落）：数字の変化。副次的な変化も書く
6. 今後（1段落）：次に何をしたいか
```

**4のつまずきを書くと、事例の信頼度が上がる。** すべて順調だった事例は読まれるが、信じられない。

## お客様の声（顧客の発言を引用する部分）

| 要素 | 中身 |
|---|---|
| 発言者 | 会社名・部署・役職。可能なら氏名 |
| 発言 | 話し言葉のまま。整えすぎない |
| 文脈 | どの質問への答えか |

- ⭕️「以前は月末の3日間、ずっと集計をしていました。今はその時間がまるごとなくなっています」
- ❌「大変満足しております。今後ともよろしくお願いいたします」

**感想ではなく、行動や時間の変化を語ってもらう。** 満足度の表明は情報量がゼロ。

---

## 使える言い回し

| 場面 | 表現 |
|---|---|
| 変化を書く | ◯◯を3日からゼロへ／1か月から9日へ／集計時間は3分の1へ |
| 削減率を書く | 業務負担を約60%削減／人事労務工数、70％削減 |
| 制約を書く | 社用端末なしの現場にも9割浸透／70人の多角化経営を1人で支える |
| 旧来のやり方を書く | ハンコと紙の非効率・属人性から脱却／脱・情報管理の属人化 |
| 属性を添える | （製造業・メーカー、51〜100名） |
| 現場の言葉を使う | ハンコリレー／すれ違わない／いつでも聞ける安心 |

---

## やらないこと

| ❌ | なぜ | ⭕️ |
|---|---|---|
| A社様の導入事例 | タイトルに情報がない | 勤怠集計が3日から1日に短縮。ハンコと紙から脱却 |
| 業務効率が大幅に改善しました | 数字がない | 集計時間が3日から1日になりました |
| 大変満足しています | 感想は情報量ゼロ | 月末の3日間の集計作業が、なくなりました |
| （業種・規模の記載なし） | 読み手が自分に当てはめられない | 業種と従業員数レンジを必ず添える |
| 導入はスムーズに進みました | 信じられない | 最初の2か月は現場から質問が集中しました |
| 弊社のソリューションにより実現 | 主語が自社になっている | 主語は顧客。自社は道具として登場させる |
