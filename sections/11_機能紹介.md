# 機能紹介

サービスサイトの機能一覧・特徴ページ。
**見出しは検索語そのまま、説明文で価値を書く。** ここを逆にすると、検索でも読み手でも負ける。

---

## このセクションに書くこと

| 要素 | 必須 | 中身 |
|---|---|---|
| 機能名 | ◎ | 検索されている言葉をそのまま使う。造語にしない |
| 何が変わるか | ◎ | 機能の説明ではなく、担当者の作業がどうなるか |
| 手段 | ○ | どうやってそれを実現するか |
| 対象者 | ○ | 誰が使う機能か |

---

## 型

```
機能名（検索語そのまま）
　→ （手段）で、（到達点）へ
```

SmartHRの機能説明は、ほぼ全部この1文型で揃っている。**機能が多いときほど構文を揃える。**

---

## 事例

### SmartHR（[機能紹介](https://smarthr.jp/function/)）

**カテゴリ見出し**
> 入社から退社まで、あらゆる労務管理がこれひとつ！
> データにもとづく戦略人事の推進で、従業員のポテンシャルを最大化
> 従業員が迷わず、業務が止まらないあらゆる業務をスマートに

**個別機能**
> **給与計算**　データ入力レス×チェック作業スリム化で、不安のない給与計算へ
> **勤怠管理**　労務担当者も従業員もカンタン操作、勤怠管理+αで残業削減へ
> **入社手続き・雇用契約**　個人情報の収集から届出書類の作成・提出まで、オンラインで完結
> **給与明細**　給与明細や源泉徴収票の作成・配付をペーパーレス化
> **文書配付**　従業員ごとに差し込む内容の異なる文書の作成と配付が簡単に
> **年末調整**　従業員とのやりとりまで効率化できる、ペーパーレス年末調整

**効いている点**
- **機能名が全部、検索される一般名詞。** 「給与計算」「勤怠管理」「年末調整」。独自の名前を付けていない。これがSEOの土台になる。
- 説明文は「（手段）で、（到達点）へ」で統一。**手段と結果を「で」で1文につないでいる**ので、機能の説明と価値の説明が同時に済む。
- 「不安のない給与計算へ」「残業削減へ」と、**到達点を担当者の状態で書いている**。機能のスペックを書いていない。
- 「入社から退社まで」「個人情報の収集から届出書類の作成・提出まで」と、**範囲を「〜から〜まで」で示す**言い方が繰り返し出てくる。

## 見出しにキーワードを入れるときのルール

| ルール | ❌ | ⭕️ |
|---|---|---|
| 機能名は一般名詞のまま | スマート給与エンジン | 給与計算 |
| キーワードを詰め込まない | 勤怠管理・勤怠システム・勤怠打刻がカンタンな勤怠管理 | 勤怠管理 |
| 説明文でキーワードを繰り返さない | 給与計算を、給与計算の手間なく給与計算できます | データ入力レスで、不安のない給与計算へ |
| 見出しは名詞、説明は文 | 給与計算がラクになります（見出し） | 給与計算（見出し）／データ入力レスで〜（説明） |
| 造語を使うなら併記 | Talent Canvas | キャリア台帳（Talent Canvas） |

**検索語は見出しに1回。説明文では言い換える。** 同じ語を繰り返しても順位は上がらず、読みにくくなるだけ。

## 使える言い回し

| 場面 | 表現 |
|---|---|
| 手段と結果をつなぐ | データ入力レス×チェック作業スリム化で、不安のない給与計算へ |
| 範囲を示す | 入社から退社まで／収集から作成・提出まで、オンラインで完結 |
| 対象者を2者書く | 労務担当者も従業員もカンタン操作 |
| 状態の変化を書く | 〜が簡単に／〜をペーパーレス化／〜へ |
| カテゴリをまとめる | あらゆる◯◯がこれひとつ／〜で、△△を最大化 |
| 付加価値を示す | 勤怠管理+αで残業削減へ |

## やらないこと

| ❌ | なぜ | ⭕️ |
|---|---|---|
| 高機能なUIで快適な操作性を実現 | スペックの説明で、誰が何をするか不明 | 労務担当者も従業員もカンタン操作 |
| 業務を効率化します | 何がどうなるか不明 | 給与明細の作成・配付をペーパーレス化 |
| AIを活用した次世代型ソリューション | 検索語がなく、中身もない | 年末調整（機能名）＋ 何が減るかを1文 |
| 独自機能「◯◯ナビ」搭載 | 造語だけでは検索されない | キャリア台帳（◯◯ナビ） |
| 豊富な機能を取り揃えています | 数も中身もない | 労務管理7機能、タレントマネジメント8機能 |
