# サービス紹介

サービスページのリード文と、各メニューの説明文。
**読み手はまだ関心がない。** サービス名から書き出さず、対象と用途を先に出す。

---

## このセクションに書くこと

| 要素 | 必須 | 中身 |
|---|---|---|
| 誰向けか | ◎ | 対象を名指しする。「BtoB企業の」「Webサイト運営者の」 |
| 何をするサービスか | ◎ | 動詞で言い切る。「制作します」「ご提案します」 |
| 対応範囲 | ◎ | どこからどこまで。「調査から公開後の改善まで」 |
| 根拠 | ○ | なぜできるのか。知見・実績・体制 |
| 結果 | ○ | 何が変わるか。数字があれば数字で |

---

## 型

### リード文の型
```
1文目：誰向けか（対象を名指し）
2文目：何をするサービスか（動詞で言い切る）
3文目：結果として何が変わるか
```

### 個別メニューの型
```
（前提となる考え方や状況）＋（何にもとづいて）＋（何をするか）。
```
ベイジのメニュー説明は全部この1文型で揃っている。**メニューが複数あるときは構文を揃える**と、比較しやすくなる。

---

## 事例

### ベイジ（[サービス](https://baigie.me/service/)）

**リード文**
> ウェブサイトの制作以外に、調査や戦略のコンサルティングから、アプリケーションのUI/UXデザイン、コンテンツ制作まで。お客さまの事業課題に応じて最適なメニューをご提供しています。

**個別メニュー**
> BtoBマーケティングの特性と全体像を理解し、綿密な調査と戦略にもとづいて事業に貢献するウェブサイトを制作します。

> あらゆるステークホルダーから優先すべきターゲットを選定し、広報やIRなどの目的にあわせた企業のウェブサイトを制作します。

> マーケティング活動全体の整理と定性/定量調査によってウェブサイトの課題・目標を明確にし、顧客目線での改善方針をご提案します。

> 机上の空論や単なる表層的なロゴなどの制作ではなく、BtoB企業ならではの経営に影響を与える現実的なブランディングをご提案します。

> ビジネス要件の整理やコンセプト設計から、リサーチ、UIデザイン、UXライティング、フロントエンド実装まで一貫して対応します。

> 自社メディアで培った知見と独自メソッドをもとに、持続可能で事業の成果につながるオウンドメディアの立ち上げ・運営を支援します。

**効いている点**
- 全メニューが「〜にもとづいて／〜によって／〜をもとに、〜します」という**同じ構文で揃っている**。読み比べやすい。
- 「〜から〜まで」で範囲を明示する言い方が繰り返し出てくる。範囲が曖昧だと発注できない。
- 「机上の空論や単なる表層的なロゴなどの制作ではなく」と、**やらないことを先に否定してから**本題に入る型。差別化の書き方として強い。
- 「持続可能で」「現実的な」など、期待値を上げすぎない形容が入っている。

### ギフティ（[トップ](https://giftee.co.jp/)）— 事業が複数あるときの並べ方

> **giftee（個人向け）**　オンラインで手軽にギフトを贈れるサービス。「ありがとう」「おめでとう」「おつかれさま」などのキモチに添えてすぐに贈れるカジュアルギフトを取り揃えています。

> **giftee for Business（法人・従業員向け）**　デジタルギフトを活用した法人向けソリューションです。販促キャンペーンの景品やお客様への謝礼、従業員への福利厚生など、ビジネスにおける様々なシーンに対応しています。

> **eGift System（eギフト発行企業向け）**　商品やサービスをeギフト化し、"贈る"を拡げることでブランド体験が深まり、新たなファン獲得やロイヤリティ向上を実現するサービスです。

> **e街プラットフォーム（自治体向け）**　自治体・地域の課題を解決するデジタルプラットフォーム。

**効いている点**
- **事業名の直後にかっこ書きで対象を書いている。** 5事業あっても、読み手は自分の該当事業を1秒で選べる。
- 各説明に**利用シーンを列挙している**（販促キャンペーンの景品／謝礼／福利厚生）。「様々なシーン」だけで終わらせず、直前に実例を3つ置いている。
- サービス名が英語でも、説明は全部日本語。名前で分からせようとしていない。

### カワサキグリーンエナジー（[トップ](https://kgen.co.jp/)）

> 工場や事業所が保有する電源を有効に活用し、省エネとコスト削減を支援。また、暮らしを支える施設には、まちで生まれた電気を届ける電力の地産地消サービスをご提案

> 電力小売事業・電力の地産地消支援・発電余力活用の3つの事業を柱とし

**効いている点**：**顧客の種類ごとに提供物を書き分けている**（工場・事業所には省エネ／暮らしを支える施設には地産地消）。同じサービスを全員に売ろうとしていない。

### サンフロロシステム（[トップ](https://www.sunfluoro.co.jp/)）

> タンクやコンテナをはじめ、配管や塔、槽などの各種設備部材に対して、用途や使用環境に応じたライニングを提供しています。

**効いている点**：対応物を実名で6つ列挙してから「各種設備部材」とまとめている。**「各種」を先に書かず、後ろに置く。** 順序が逆だと何も伝わらない。

### ウィルゲート（[SEOサービス](https://www.willgate.co.jp/seo/)）

> 株式会社ウィルゲートは、Webサイト運営者のSEO対策の課題を解決する新サービス「SEO施策反映代行サービス」の提供を開始しました。

> SEO施策の提案から実行までをワンストップでサポートする新サービス

**効いている点**：「提案から実行まで」と範囲を書いたうえで「ワンストップ」を使っている。**「ワンストップ」だけでは意味が伝わらない。**必ず範囲とセットにする。

### ベイジ 採用サイト支援（[採用](https://baigie.me/recruit/)）

> 採用人事戦略から共に考える採用サイトに強いウェブ制作会社です。採用に精通したコンサルタントがお客さまの採用サイトの問題を解決します。

**効いている点**：「〜に強い◯◯会社です」という名乗り方。強みと業種を1語で接続できる。

## 使える言い回し

| 場面 | 表現 |
|---|---|
| 範囲を示す | 〜から〜までを一貫して対応します／〜から〜までをサポートします |
| 根拠を示す | 綿密な調査と戦略にもとづいて／自社メディアで培った知見と独自メソッドをもとに |
| 対象を絞る | 〜の特性と全体像を理解し／〜ならではの |
| 否定から入る | 〜ではなく、〜をご提案します |
| 名乗る | 〜に強い◯◯会社です |
| 順序を示す | まず〜し、そのうえで〜します |
| 期待値を調整する | 現実的な／持続可能な／可能な範囲で |
| 事業ごとに対象を示す | サービス名（個人向け）／サービス名（自治体向け） |
| 顧客で書き分ける | 工場や事業所には〜を、暮らしを支える施設には〜をご提案 |
| 実例を先に置く | タンクやコンテナをはじめ、配管や塔、槽などの各種設備部材に対して |
| シーンを列挙する | 販促キャンペーンの景品やお客様への謝礼、従業員への福利厚生など |

## やらないこと

| ❌ | なぜ | ⭕️ |
|---|---|---|
| 「SEO Booster」は画期的なサービスです | サービス名から始めない | SEOに課題を持つBtoB企業向けに、記事制作と効果測定を担当します |
| 成果を最大化します | 何をするか不明 | 月4本の記事を公開し、3か月ごとに効果を測定します |
| ワンストップで対応します（単独で） | 範囲が不明 | 調査から公開後の改善まで、ワンストップで対応します |
| 貴社に最適なプランをご提案します | 中身がない | 現状のサイトを見たうえで、改善点を3つお伝えします |
| 業界No.1の実績 | 根拠の注記がない | 調査会社名・調査期間・調査対象を注記する |
