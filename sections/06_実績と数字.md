# 実績・数字

導入社数、支援実績、継続率などの書き方。
**数字が出せないなら、その一文を消す。** あいまいな数字を書かない。

---

## このセクションに書くこと

| 要素 | 必須 | 中身 |
|---|---|---|
| 数字 | ◎ | 半角の算用数字。3桁ごとにカンマ |
| 単位 | ◎ | 社・件・名・％。何を数えたかがわかる単位 |
| 基準時点 | ◎ | かっこ書きで「（2026年8月時点）」 |
| 母数・調査主体 | ○ | 割合を書くなら必須 |

---

## 型

```
数字 ＋ 単位 ＋ 基準時点（かっこ書き）
```

複数並べるときは、**単位を変える**と情報量が増える。同じ単位を3つ並べても伝わる量は増えない。

---

## 事例

### 才流（[トップ](https://sairu.co.jp/)）

> 260社以上の支援実績
> 400件以上のプロジェクト実績
> 500件以上のメソッド開発

**効いている点**：社数・件数・開発数と単位を変えている。顧客の数、仕事の数、資産の数の3方向から会社の厚みを示している。

### freee（[会社概要](https://corp.freee.co.jp/company/)）

> 従業員数 1,901人（※2025年6月末時点、連結会社の総数）

**効いている点**：基準時点と集計範囲（連結会社の総数）の両方を注記している。**「何を数えたか」まで書くのが正しい形。**

### ウィルゲート（[SEOサービス](https://www.willgate.co.jp/seo/)）

> SEO対策に取り組む（または検討している）9割を超えるWeb担当者が

**効いている点**：割合を出すときに、母集団の条件を先に絞っている。「9割の企業が」と書くより誠実。

## 使える言い回し

| 場面 | 表現 |
|---|---|
| 実績を書く | 支援実績 1,500社（2026年8月時点） |
| 集計範囲を注記する | （※2026年6月末時点、連結会社の総数） |
| 母集団を絞る | 〜に取り組む（または検討している）担当者のうち |
| 継続を示す | 平均継続期間 2年3か月 |
| 変化を示す | 1本4時間かかっていた作業が、2時間になりました |
| 幅を示す | 月額15万円から |

---

## やらないこと

| ❌ | なぜ | ⭕️ |
|---|---|---|
| 多くの企業様にご利用いただいております | 数がない | 導入実績125社（2026年8月時点） |
| 業界トップクラスの実績 | 検証できない | 支援実績1,500社（2026年8月時点） |
| 大幅に工数を削減できます | 量が不明 | 1本4時間が、2時間になります |
| 顧客満足度98% | 母数と調査方法がない | 顧客満足度98%（2026年◯月実施、回答数n=124） |
| ◯◯No.1 | 根拠の注記がない | 調査会社名・調査期間・調査対象を必ず注記する |
| 圧倒的な実績 | 形容詞に逃げている | 数字に置き換える。書けないなら削除する |
