# 会社紹介

「私たちについて」「About」「企業情報」にあたるページの本文。
読み手は、この会社が何をしていて、信頼できるかを30秒で判断しようとしている。

---

## このセクションに書くこと

| 要素 | 必須 | 中身 |
|---|---|---|
| 何をしている会社か | ◎ | 業種＋提供物を1文で。「ウェブ制作会社」「統合型経営プラットフォームの開発・提供」 |
| 誰に向けているか | ◎ | 対象顧客。「BtoB企業」「スモールビジネス」「ベンチャー企業」 |
| 事業領域 | ◎ | 2〜4個の列挙。事業名は具体名詞で |
| 拠り所 | ○ | 何を強みにしているか。調査・メソッド・技術・人 |
| 規模の数字 | ○ | 設立年、従業員数、支援社数。基準時点を添える |
| 方針・姿勢 | △ | 成長方針や仕事の進め方。ここが差別化になる |

**「私たちは、お客様に寄り添い、最高の価値を提供し続ける会社です」だけで終わらせない。**
このセクションで読み手が知りたいのは、姿勢ではなく事実。

---

## 型

### 型A：事業説明先行（BtoBコーポレートの標準）
```
何をしている会社か（1文）
 → 対象顧客
 → 事業領域の列挙
 → 規模の数字
```

### 型B：理念先行
```
問題意識（1〜2文）
 → だから何をしているか
 → 事業領域
```
代表メッセージと役割が重なる。両方に置くと冗長になるので、どちらか一方に寄せる。

### 型C：数字先行
```
数字3つ（設立年・支援社数・実績数）
 → 事業の説明
```
支援実績が積み上がっている会社に向く。

## 事例

### ベイジ（[会社概要](https://baigie.me/company/)）

> 「ウェブで企業の力を引き出す」をミッションと考え、お客さまの成功に貢献することを喜びとし、仕事と人生に真摯に向き合っているウェブ制作会社

> ベイジの力の源は、間違いなくスタッフにあります。向上心が高く真面目なスタッフが揃い、困っている人を率先して助ける文化が根付いています。

> 良質なコンテンツの発信によって認知を拡大し、自然とお問い合わせを集めるインバウンドマーケティングを基本方針としています。

> 急成長は目指さずに、手堅く着実な成長を続けてきました。

**構造**：ミッション → 力の源（人） → 集客の方針 → 成長の方針
**効いている点**
- 最後が体言止めの「ウェブ制作会社」で、業種が明確に着地している。
- 「急成長は目指さずに」と、**やらないことを書いている**。会社紹介で差がつくのはここ。
- 自社の集客手段まで開示していて、書いていることに裏付けがある。

### 才流（[トップ](https://sairu.co.jp/)）

> 独自の調査と現場での実践に基づいたメソッドを用いて各領域のエキスパートがお客様のビジネス課題を解決します。

> 260社以上の支援実績／400件以上のプロジェクト実績／500件以上のメソッド開発

**効いている点**
- 「独自の調査と現場での実践に基づいた」で、**何を根拠にしているか**を先に置いている。
- 数字を3つ並べ、単位を変えている（社数・件数・開発数）。同じ単位を並べるより情報量が増える。

### YOSCA（[トップ](https://yosca.jp/)）

> テキストに関わるすべての制作物を、編集者品質でつくります。

> SEO記事・取材・導入事例・社内報・書籍・LP・ホワイトペーパー・メルマガ・プレスリリース・文字起こし・動画字幕・SNS——2011年創業、業界経験ライター11,000人以上 × ベテラン編集者で、貴社のコンテンツ制作・運用を「安心感」で支えます。

**効いている点**
- **対応物を12個、実名で列挙している。** 「幅広く対応」と書く代わりに全部並べることで、読み手が自分の案件を見つけられる。
- 「編集者品質で」という**自社基準を1語で名付けている**。品質を主張するときの型として使える。
- 創業年・登録ライター数・体制（ライター×編集者）を1文に畳んでいる。

### ニジボックス（[トップ](https://nijibox.jp/)）

> UI UXデザインとテクノロジーでビジネスを成長させ続ける

> UXデザイン／UIデザイン／データマネジメント／開発／動画／イラスト・アニメーション

**効いている点**：手段（UI UXデザインとテクノロジー）と目的（ビジネスを成長させ続ける）を1文で接続している。事業領域は名詞で列挙し、説明を足していない。会社紹介の最小構成。

### サンフロロシステム（[トップ](https://www.sunfluoro.co.jp/)）— 製造業の手本

> サンフロロシステムは、ガス透過を抑える高密度m-PTFE GB（APV）や、耐食性に優れたPTFE・PFAフッ素樹脂シートライニングの専門企業です。大阪府茨木市から、独自技術で化学・半導体工場の長寿命化を支援します。

> 産業を支える設備は、薬品・熱・圧力など過酷な条件の中で稼働しています。その設備の内部を守り、本来の性能を発揮し続けるために欠かせないのが、サンフロロシステムのライニング技術です。

> 設備内部の品質が安定しているからこそ、そこで扱われる原料や製品の価値も守られる。私たちが守っているのは、設備だけではなく、その先にある製品の価値、そして産業を支える品質の土台そのものです。

**効いている点**
- 1文目に**専門用語と地名と対象産業**が全部入っている。「化学・半導体工場の」で誰向けかが確定する。専門用語を避けずに、対象を絞る道具として使っている。
- **具体 → 抽象の順で上がっている。** 「設備を守る」→「製品の価値を守る」→「品質の土台」。抽象語を先に置かず、最後に到達させる。この順序なら抽象語が浮かない。
- 「私たちが守っているのは、設備だけではなく、〜」という**否定を挟んで意味を拡張する構文**。会社紹介の締めに使える。

### マルニ工業（[トップ](https://maruni-ind.co.jp/)）

> 私たちは、日本唯一のパンク修理材総合メーカーです。

> 私たちの製品は、パンク修理を通じて自転車や自動車の安全で快適な走りを守るとともに、「交換ではなく修理」という選択を広げることで限りある資源を活かす循環型の社会づくりにも貢献しています。

**効いている点**
- **「日本唯一の◯◯メーカーです」と1文で名乗り切っている。** ニッチな会社ほどこの型が効く。範囲を狭めるほど、言い切れる。
- 「交換ではなく修理」と、**自社の立場を2語の対比で示している**。長い説明より速い。

### カワサキグリーンエナジー（[トップ](https://kgen.co.jp/)）

> 川崎重工グループのカワサキグリーンエナジーは、低炭素エネルギーの提供を通じて企業の脱炭素化を支援する新電力会社

> 川崎重工グループの「ものづくり」に、新たな「エネルギーサービス」を掛け合わせる。それが、当社のエネルギーソリューション

**効いている点**：**掛け算の構文**。「AにBを掛け合わせる。それが当社の◯◯」は、グループ会社や新規事業の説明にそのまま使える。

### 住宅ファミリー社（[トップ](https://www.jyuutaku-family.co.jp/)）

> 新しい暮らしの準備や、これまで大切にしてきた場所の管理・活用まで。住宅ファミリー社は、物件の売買・賃貸・管理、そして土地や建物の有効活用まで幅広く手がける不動産会社です。

**効いている点**：**時間軸の対比（これから／これまで）で対応範囲を示している。** 「幅広く」だけで終わらせず、直前に具体的な2方向を置いているので、幅広さが実感できる。

### ユニフォームネット（[トップ](https://www.uniform-net.jp/)）

> ユニフォームに、無限の提案力を。

> 従業員の満足度を向上させる。採用活動の武器にしたい。従業員への支給品でありながらブランディングアイテムでもある。袖を通した瞬間から、人をプロフェッショナルに変えてしまう力さえある。

**効いている点**：商材が地味なときの書き方。**買い手の言葉（〜したい）と、商材の効果を、体言止めと常体で連打している。** 敬体の説明文が続く中に置くと、テンポが変わって読ませられる。

### ギフティ（[トップ](https://giftee.co.jp/)）

> giftee（個人向け）：オンラインで手軽にギフトを贈れるサービス。
> giftee for Business（法人・従業員向け）：デジタルギフトを活用した法人向けソリューションです。

> e街プラットフォーム（自治体向け）：自治体・地域の課題を解決するデジタルプラットフォーム。

**効いている点**：**事業名のすぐ後ろに、かっこ書きで対象を書いている。** 事業が複数あるときは、この1手で読み手が自分の該当事業を選べる。

**効いている点**：設立年・創業者・事業・対象顧客を1文ずつで畳んでいる。会社紹介の骨格をそのまま使える。

## 業種による名乗り方の違い

同じ「会社紹介」でも、業種によって1文目の作り方が変わる。

| 業種 | 1文目の作り方 | 例 |
|---|---|---|
| 製造業・技術系 | 技術名＋対象産業＋地名で絞る | ガス透過を抑える〜の専門企業です。大阪府茨木市から、化学・半導体工場の長寿命化を支援します |
| ニッチトップ | 「日本唯一の」「〜専門の」で言い切る | 私たちは、日本唯一のパンク修理材総合メーカーです |
| グループ会社 | 親会社の資産×自社の役割の掛け算 | ◯◯グループの「ものづくり」に、新たな「△△」を掛け合わせる |
| 不動産・サービス業 | 対応範囲を2方向の対比で示す | 新しい暮らしの準備や、これまで大切にしてきた場所の管理・活用まで |
| IT・SaaS | 対象顧客＋提供物 | スモールビジネス向けに、統合型経営プラットフォームを開発・提供しています |
| 制作会社・代理店 | 「〜に強い◯◯会社」で強みと業種を接続 | 採用サイトに強いウェブ制作会社です |

**専門用語は、避けるのではなく対象を絞る道具に使う。**
サンフロロシステムが「m-PTFE」「PFAフッ素樹脂シートライニング」を1文目に置けるのは、読み手が化学・半導体工場の設備担当者だから。
一方、一般消費者向けのページで同じことをすると読まれない。**読み手が誰かで、専門用語の可否が決まる。**

## 使える言い回し

| 場面 | 表現 |
|---|---|
| 業種を名乗る | 〜に強いウェブ制作会社です／〜の開発・提供をしています |
| 対象を絞る | 〜を必要とする企業に向けて／〜に携わるすべての人が |
| 一貫性を示す | 〜から〜までを一貫して手がけています |
| 根拠を示す | 独自の調査と現場での実践に基づいた／自社メディアで培った知見をもとに |
| 方針を示す | 〜を基本方針としています／〜は目指さずに、〜を続けてきました |
| 継続を示す | 設立時から〜してきました／創業から◯年、〜を続けています |
| 唯一性を名乗る | 私たちは、日本唯一の◯◯メーカーです／〜専門の△△です |
| 掛け算で説明する | ◯◯に、新たな△△を掛け合わせる。それが、当社の□□ |
| 対比で範囲を示す | 〜の準備や、これまで〜してきた場所の管理・活用まで |
| 立場を2語で示す | 「交換ではなく修理」という選択を広げる |
| 意味を拡張する | 私たちが守っているのは、◯◯だけではなく、その先にある△△です |
| 事業ごとに対象を示す | サービス名（個人向け）／サービス名（法人向け） |

## やらないこと

| ❌ | なぜ | ⭕️ |
|---|---|---|
| 私たちは、お客様に寄り添い、最高の価値を提供し続ける会社です | 何をしているか不明 | 当社は、BtoB企業向けのウェブサイト制作をしています |
| 常に業界の最先端を走り続けています | 検証できない | 2006年の設立以来、SEOを軸にした支援を続けています |
| 豊富な実績があります | 数字がない | 支援実績1,500社（2026年8月時点） |
| 総合的なソリューションをワンストップで提供 | 範囲が不明 | 調査・戦略設計・制作・公開後の改善までを担当します |
