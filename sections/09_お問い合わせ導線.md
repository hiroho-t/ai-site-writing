# お問い合わせ導線

CTA（行動を促す文）。ボタン、フォームの前置き、記事末の誘導。

**行動を促す文には、所要時間・費用・次に何が起きるか、のいずれかを添える。**
読み手が押すのをためらう理由は、たいていこの3つのどれかがわからないから。

---

## このセクションに書くこと

| 要素 | 必須 | 中身 |
|---|---|---|
| 何が起きるか | ◎ | 押した先で何をするか。「30分の打ち合わせ」「資料のダウンロード」 |
| 費用 | ◎ | 無料なら無料と書く |
| 所要時間・分量 | ○ | 「30分」「全12ページ」「入力3分」 |
| 相手の準備 | ○ | 事前に用意するものがあるか |
| その後の流れ | ○ | 送信後いつ連絡が来るか |

---

## 型

```
何が起きるか ＋ 費用または所要時間 ＋ （その後の流れ）
```

感嘆符は使わない。押し売りの声になる。

---

## 事例

### ベイジ（[よくある質問](https://baigie.me/faq/)）

> 公開後1週間をめどに、CMSのオペレーションをレクチャーします。

**効いている点**：CTAそのものではないが、**「いつ・何をするか」を書く姿勢**がサイト全体で一貫している。この書き方をCTAに持ち込むと、そのまま良い導線になる。

### 才流（[トップ](https://sairu.co.jp/)）

> WebやAIでは出てこない情報や横のつながりを提供します

**効いている点**：申し込む価値を、**手に入るものの形**で書いている。「ぜひご参加ください」ではなく、参加すると何が得られるかを書いている。

### YOSCA（[トップ](https://yosca.jp/)）

> 業界経験ライター × 編集者校正で、検索上位＆読まれる記事を継続供給。月数本〜数十本の運用に対応します。

**効いている点**：対応可能な量（月数本〜数十本）を書いている。**発注できる規模がわかると、問い合わせのハードルが下がる。**

---

## 使える言い回し

| 場面 | 表現 |
|---|---|
| 無料を示す | ご相談は無料です |
| 所要時間を示す | 30分のオンライン打ち合わせから始められます／入力は3分ほどです |
| 分量を示す | 全12ページ・無料 |
| 何をするか示す | 現状のサイトを見たうえで、改善点をお伝えします |
| 対応規模を示す | 月数本〜数十本の運用に対応します |
| その後を示す | 3営業日以内に、担当者からご連絡します |
| 押し付けない | 検討中の段階でもかまいません／情報収集のみのご相談も受け付けています |

---

## やらないこと

| ❌ | なぜ | ⭕️ |
|---|---|---|
| まずはお気軽にご相談ください！ | 何が起きるか不明。感嘆符が押し売りに響く | ご相談は無料です。30分のオンライン打ち合わせから始められます |
| 今すぐお問い合わせ | 急かしている | 資料をダウンロードする（全12ページ・無料） |
| 私たちにお任せください | 中身がない | 現状のサイトを見たうえで、改善点を3つお伝えします |
| お問い合わせはこちら（だけ） | 判断材料がない | 費用・所要時間・その後の流れのどれかを添える |
| 無料相談実施中!! | 感嘆符の重ね打ち | 相談は無料です |
| 今なら初期費用0円 | 期限が不明な限定表現 | 2026年12月末までのお申し込みは、初期費用がかかりません |
