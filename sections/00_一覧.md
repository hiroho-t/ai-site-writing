# セクション一覧

サイトの面（セクション）ごとに、「何を書くか」と「他社がどう書いているか」をまとめている。
書きたい面のページを開いて、**このセクションに書くこと** → **型** → **事例** → **使える言い回し** の順に読む。

---

## どのセクションも同じ構成で書いている

| 見出し | 中身 |
|---|---|
| このセクションに書くこと | 構成要素のチェックリスト。◎は必須、○は推奨、△は任意 |
| 型 | 段落構成のテンプレート |
| 事例 | 他社の実文面と、効いている点の分析 |
| 使える言い回し | 場面ごとの表現集。そのまま流用できる |
| やらないこと | このセクション特有のNGと、その理由 |

## まだ事例が薄い面

- 沿革・ヒストリー
- 導入事例・お客様の声
- 記事のリード文（メディア系：創業手帳、NewsPicks、PIVOT、LIGブログ）
- プライバシーポリシー・利用規約の導入文

会社を足すときは、**コーポレート文体と記事・メディア文体を混ぜない**。
