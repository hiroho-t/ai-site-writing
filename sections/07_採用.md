# 採用

採用ページの導入文、求める人物像、カルチャーの説明。
**盛らない。** 入社後に「話が違う」となる書き方を避ける。

---

## このセクションに書くこと

| 要素 | 必須 | 中身 |
|---|---|---|
| 何をしている会社か | ◎ | 求職者は事業を知らない前提で書く |
| 何を大切にしているか | ◎ | 判断基準。抽象語ではなく行動で書く |
| どんな人と働きたいか | ◎ | 属性ではなく、行動や姿勢で書く |
| 働き方の事実 | ○ | 制度、勤務形態、評価の仕組み |
| きれいごとでない部分 | ○ | 難しさ、いま挑戦していること |

---

## 型

```
事業の説明（求職者は知らない前提）
 → 何を大切にしているか（行動で書く）
 → いま何に挑戦しているか（難しさも書く）
 → どんな人と働きたいか
```

---

## 事例

### SmartHR（[私たちについて](https://smarthr.co.jp/about/)）

> 現在、私たちは最速で日本社会の「well-working」を達成するために、スタートアップのスピード感を失わずに規模を拡大していくという難題にチャレンジしています。人事労務領域にとどまらない事業拡大を推進するとともに、従業員一人ひとりが働きやすさとやりがいを感じられる「働きがい」のある組織づくりに取り組んでいます。

**効いている点**：「難題にチャレンジしています」と、**まだ達成していないことを書いている**。採用文で最も信頼されるのはここ。

### SmartHR（[会社情報](https://smarthr.co.jp/company/)）

> 私たちは一緒に働くメンバーを探しています。SmartHRが目指すのは誰もがその人らしく働ける社会。ミッション・バリューへの共感を何よりも大切に考え、一緒に働くメンバーを探しています。

**効いている点**：求める条件を「スキル」ではなく「ミッション・バリューへの共感」と明示している。判断基準が1つに絞られている。

### SmartHR バリューの評価連動（[私たちについて](https://smarthr.co.jp/about/)）

> バリューに合致する行動ができているかは、評価項目にも組み込まれています。

**効いている点**：理念が制度に接続していることを1文で示している。**「大切にしています」だけの会社との差がここで出る。**

### サイボウズ（[企業理念](https://cybozu.co.jp/company/philosophy/)）

> 社内では「アホはいいけど嘘はダメ」という言葉で表される、嘘をつかない・隠しごとをしない姿勢をコミュニケーションの土台にしています。

> 他人のせいにせず、問題を感じたら積極的に質問し、質問に対しては誠実に回答する行為（質問責任と説明責任）を果たすことを重視しています。

**効いている点**
- 社内で実際に使われている言葉をそのまま出している。**カルチャーは、社内語をそのまま見せるのが一番早い。**
- 「主体性」という抽象語を「質問責任と説明責任」という具体的な行為に定義し直している。

### ベイジ（[会社概要](https://baigie.me/company/)）

> ベイジの力の源は、間違いなくスタッフにあります。向上心が高く真面目なスタッフが揃い、困っている人を率先して助ける文化が根付いています。

> 急成長は目指さずに、手堅く着実な成長を続けてきました。

**効いている点**：「急成長は目指さない」と方針を明示している。**合わない人が自分で気づける書き方**は、採用の質を上げる。

## 使える言い回し

| 場面 | 表現 |
|---|---|
| 未達成を書く | 〜という難題にチャレンジしています／いま取り組んでいる最中です |
| 判断基準を1つに絞る | 〜への共感を何よりも大切に考えています |
| 制度に接続する | 〜は、評価項目にも組み込まれています |
| カルチャーを見せる | 社内では「〜」という言葉で表される、〜を土台にしています |
| 抽象語を定義し直す | 主体性の発揮とは、〜を指します |
| 方針を明示する | 急成長は目指さずに、〜を続けてきました |

## やらないこと

| ❌ | なぜ | ⭕️ |
|---|---|---|
| アットホームな職場です | 何も伝わらない | 全社員が週1回、同じ資料で進捗を共有しています |
| 風通しの良い社風 | 検証できない | プライバシーとインサイダー以外の情報を公開しています |
| 主体性のある方を求めています | 抽象語のまま | 問題を感じたら質問し、質問には誠実に答える方 |
| 成長できる環境があります | 誰が何をするか不明 | 入社後3か月は、専任の先輩が週1回の面談をします |
| 若手でも活躍できます | 「若手は活躍しにくい」という前提が隠れている | 入社1年目から、案件の担当を持ちます |
| やりがいのある仕事です | 感想であって事実でない | いま挑戦していることと、その難しさを書く |
