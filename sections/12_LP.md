# LP（ランディングページ）

**対象はBtoBのLPに限る。** 資料ダウンロード、無料相談、ウェビナー申込、代理店・生産者募集など。
対象外は、キャラクターの口調やタメ口で書かれたLP。**感嘆符や勢いのある表現そのものは除外しない。**

---

## LPは新しい面ではない

LPは、**既存の面を1ページに縦積みしたもの**。各パーツの書き方は、それぞれのページを見る。

| 順番 | パーツ | 参照先 |
|---|---|---|
| 1 | ファーストビュー | **このページ**（LP固有） |
| 2 | 課題提起 | [05 課題提起](sections/05_課題提起.md) |
| 3 | サービスの説明 | [04 サービス紹介](sections/04_サービス紹介.md) |
| 4 | 機能・特徴 | [11 機能紹介](sections/11_機能紹介.md) |
| 5 | 導入事例・お客様の声 | [10 導入事例](sections/10_導入事例.md) |
| 6 | 実績の数字 | [06 実績・数字](sections/06_実績と数字.md) |
| 7 | 導入の流れ | **このページ** |
| 8 | よくある質問 | [08 よくある質問](sections/08_よくある質問.md) |
| 9 | オファーとフォーム | **このページ** ＋ [09 お問い合わせ導線](sections/09_お問い合わせ導線.md) |

**LP固有なのは、ファーストビュー・導入の流れ・オファーの3つだけ。** 残りは使い回せる。

## ファーストビュー

### このパーツに書くこと

| 要素 | 必須 | 中身 |
|---|---|---|
| キャッチコピー | ◎ | 到達点を1行。10〜20字 |
| サブコピー | ◎ | 何のサービスか、または顧客の不満そのもの |
| CTA | ◎ | 押した先で何が起きるか |
| 実績の数字 | ○ | 導入社数など1つだけ |

### 型

**型A：到達点を言い切る**
```
（対象物）を、（到達点）へ。
```
> Webサイトを、成果を生む基盤へ。 ——[Studio.Business](https://studio.design/ja/business)

> バックオフィスから まるごとスマートに。 ——[SmartHR](https://smarthr.jp/)

**型B：短い言い切り ＋ サブコピーで定義**
```
（短い一言）。
（製品の定義を1文で）
```
> みんな、つくれる。
> kintone（キントーン）は、AIとノーコードで、現場の業務にフィットする業務アプリをつくれて、業務を進めるほどAI活用の土台となるデータがたまる、サイボウズの業務改善プラットフォームです。
> ——[kintone](https://kintone.cybozu.co.jp/)

**型C：顧客の不満をそのまま置く**
```
（到達点）
（顧客が言っている不満を、口語のまま2〜3行）
```
> Webサイトを、成果を生む基盤へ。
> ランディングページの修正に2週間かかる
> 文言を少し変えるだけでも費用が発生する
> ——[Studio.Business](https://studio.design/ja/business)

## 事例

### Studio.Business（[法人向けページ](https://studio.design/ja/business)）— BtoB LPの手本

**ファーストビュー**
> Webサイトを、成果を生む基盤へ。
> ランディングページの修正に2週間かかる／文言を少し変えるだけでも費用が発生する

**課題提起**
> 新たな施策を試そうにも Webサイトやオンラインサービスがボトルネックとなるケースがあります
> ・キャンペーンLPを作りたいけど制作に時間がかかる
> ・少し文言を変えたいだけなのに依頼する必要がある
> ・脆弱性やバージョンなど、運用保守のコストが高い...

**CTA**
> 法人向け製品資料を受け取る／自社での活用を相談する

**効いている点**
- **感嘆符がゼロ。** それでも読ませている。煽らなくてもLPは成立する。
- 課題提起が**担当者の作業レベルで具体的**。「業務効率が悪い」ではなく「文言を少し変えたいだけなのに依頼する必要がある」。自分の状況として読める。
- **CTAが2種類あり、検討段階で分かれている。** 「資料を受け取る」（情報収集）と「相談する」（検討中）。「お問い合わせ」1本にしていない。
- CTAが「何が起きるか」の動詞で書かれている。「受け取る」「相談する」。

### シフトラ（[LP](https://aishift.com/)）— 数字をサブコピーに置く型

> ことばを理解するAIでシフトづくりをかんたんに
> **毎月40時間かかっていた作業が、わずか10分に。**

**課題提起**
> シフトの調整に何時間も悩まされていませんか？

**特徴の見出し（6つ）**
> 現場ルールが多くても、まとまる。／現場フォーマットに、スムーズにフィット。／ほぼ手直し不要の、完成度。／業界ごとのルールにも、しっかり対応。／希望集計から承認・配布まで、自動で完結。／時間帯も時間単位も、AIが自動で最適化。

**効いている点**
- **サブコピーが数字の変化そのもの。** 「40時間 → 10分」。キャッチコピーで何のサービスかを言い、サブコピーで効果を数字で示す分業ができている。
- 特徴の見出しが**6つとも「（条件）、（結果）。」の読点区切りで揃っている。** 体言止めと言い切りが交互に来て、一覧で読みやすい。
- 「ほぼ手直し不要の」と、**言い切りを避けた表現**が混ざっている。全部を断言していないので、かえって信用できる。

### 観光AIソムリエ（[LP](https://lp.tabinuki.com/)）— 定型の課題提起を成立させる型

> こんなお悩みありませんか？
> ・観光マップはあるけど活用されていない…
> ・データ収集・分析ができていない...
> ・訪問者の回遊施策に限界...

> まちの個性を、知って・巡って・楽しんで。3つの連携サービスで、観光が動き出す。

**効いている点**
- 「こんなお悩みありませんか？」は定型句だが、**直後の3つが具体的な状況**なので機能している。定型句そのものが悪いのではなく、中身が抽象的だと死ぬ。
- サービス3つを**「知る・巡る・楽しむ」の動詞3語で束ねている。** 覚えやすく、順序にも意味がある。

### 旬の駅 生産者募集（[LP](https://farmer.syunnoeki.com/)）— 募集系LPの構成

> 契約農家さん募集中！
> 関西最大級の農産物直売所「旬の駅」は関西を中心に全国約4000名の農家さんから届いた新鮮な野菜や果物を取り扱う〜

**実績の並べ方**
> 関西地域で10店舗展開／年間来客数300万人／自社便による夜間集荷・転送／年会費無料

**応募の流れ**
> 1. 担当者との面談　2. 生産者登録　3. 出荷・搬入　4. 店内での陳列

**効いている点**
- **数字3つ＋条件1つ**の並べ方。規模（店舗数）、集客力（来客数）、体制（自社便）、コスト（年会費無料）と、応募者が知りたい4項目を1行ずつ。
- **応募の流れが4ステップの名詞のみ。** 説明を足していない。ステップが見えると、応募のハードルが下がる。
- 「夜間のうちに集荷し、翌朝各店舗の店頭に並びます」と、**時間の流れで仕組みを説明している**。

## 導入の流れ

### 型
```
ステップ番号 ＋ 名詞（〜する／〜の実施）
（必要なら1行の補足。所要期間を添える）
```

- ステップは**3〜5個**。それ以上は読まれない。
- 各ステップは**名詞または短い動詞句**。文章にしない。
- **どこまでが自社の作業で、どこからが相手の作業か**を分ける。
- 所要期間を書けるなら書く。「面談から出荷まで最短2週間」

| ❌ | ⭕️ |
|---|---|
| まずはお問い合わせいただき、担当者がヒアリングを行った後、お見積もりをご提示させていただきます | 1. お問い合わせ　2. 打ち合わせ（30分）　3. お見積もりの提示（3営業日以内） |

## オファーとフォーム前の案内

**何がもらえるかを、具体物で書く。**

> 資料をダウンロードいただけます。BtoBマーケティング・営業活動・新規事業開発などの支援をご検討中の方はご覧ください。
> ——[才流 資料ダウンロード](https://sairu.co.jp/download)

**効いている点**：**誰向けかを1文で絞っている。** 全員に配ろうとしていない。

| 添えるもの | 例 |
|---|---|
| 分量 | 全24ページ |
| 費用 | 無料 |
| 入力の手間 | 入力項目は5つ、1分ほどで完了します |
| 対象者 | 〜をご検討中の方はご覧ください |
| その後 | ご登録後、すぐにダウンロードいただけます／3営業日以内にご連絡します |
| 営業されるか | 資料請求のみのご利用でもかまいません |

**「営業の電話が来るのか」は、最も多い離脱理由。** 書ける範囲で先に答えておく。

## 表現の強さの線引き

避けるのは**強い表現そのものではなく、口調**。感嘆符や勢いのある言い回しは、BtoBのLPでも必要になる。

### 使ってよい

| 表現 | 実例 |
|---|---|
| 感嘆符 | SmartHRひとつで、業務がスピードアップ！（[SmartHR](https://smarthr.jp/)） |
| 感嘆符つきの条件訴求 | 年会費無料！／契約農家さん募集中！（[旬の駅](https://farmer.syunnoeki.com/)） |
| 「〜から解放」 | 面倒な座標設定から解放！（[Chromateach](https://nisshodenkiseigyo.com/chromateach/)） |
| 行動を促す一言 | まずはご相談ください！ |

**目安**：感嘆符は1ページに数個、1つの見出しに1つまで。連打（！！ ／ ！?）はしない。
上場企業のサービスサイトでも普通に使われている。ゼロにする必要はない。

### 避ける

口調が崩れると、BtoBでは一気に信用を落とす。

| ❌ | 何が問題か | ⭕️ |
|---|---|---|
| もう面倒な集計とはサヨナラ！ | タメ口・常体の話しかけ | 面倒な集計から解放！ |
| そんなアナタにピッタリのツールがコレ！ | キャラクターのセリフ調 | 〜をお探しの企業様に選ばれています |
| 〜って知ってた？ | 常体の問いかけ | 〜をご存じでしょうか（または削除） |
| キミの営業を変える | 馴れ馴れしい二人称 | 営業の進め方が変わります |
| 導入するっきゃない！ | 俗語 | 導入をご検討ください |
| 🎉 今だけ！ | 絵文字・顔文字 | 2026年12月末まで |

### 判別の基準

**敬体（ですます）を崩していないか。** 感嘆符の数ではなく、口調で見る。

| チェック | 基準 |
|---|---|
| 文末 | ですます体を保っているか。常体の話しかけが混ざっていないか |
| 二人称 | 「アナタ」「キミ」を使っていないか（「御社」も本文では使わない） |
| キャラクター | 誰かのセリフとして読める文になっていないか |
| 絵文字・顔文字 | 使っていないか |
| 感嘆符 | 連打していないか。1見出しに2個以上ないか |
| 略語 | 1つの見出しに略語を並べていないか（GEO/LLMO/AIOのように） |
| 誇張 | 「業界No.1」「圧倒的」に注記があるか |

**「AI検索ならミエルカ！SEOも､GEO/LLMO/AIOもこの1つで！」**（[ミエルカSEO](https://mieru-ca.com/)）が読みにくいのは、感嘆符のせいではなく、
1つの見出しに略語を4つ並べているため。**直すべきは略語の数であって、感嘆符ではない。**

## LPのSEO戦略

**LPは、検索の主戦場ではない。** 構造的な理由がある。

| LPの性質 | 検索での影響 |
|---|---|
| 1ページ完結で、内部リンクがほとんどない | サイト内での評価が伝わりにくい |
| 更新されない | 鮮度で評価されにくい |
| 画像に文字を焼き込みがち | テキストとして読まれない |
| 広告・メール・SNSからの流入が主 | 検索経由を前提に作られていない |

### だから、こう設計する

| 方針 | 具体的に |
|---|---|
| **検索はサービスサイト本体で取る** | 「勤怠管理システム」などの検索語は、サービスサイトの機能ページで狙う。LPで同じ語を狙うと共食いする |
| **LPは広告と指名検索の受け皿にする** | 「サービス名 + 料金」「サービス名 + 導入事例」で来た人が着地する場所 |
| **画像に文字を焼き込まない** | キャッチコピー・見出し・特徴はテキストで書く。AI検索でも読まれる |
| **同一キーワードのLPを量産しない** | 内容が重複し、どれも評価されなくなる |
| **noindexにするか決める** | 広告専用LPは、サービスサイトと内容が重複するならnoindexも選択肢 |

### それでもLPに入れるもの

| 要素 | 理由 |
|---|---|
| h1にサービス名と用途 | 指名検索で着地したときに、合っているか判断できる |
| FAQ | 「サービス名 + 料金」「+ 解約」などの検索意図に直答できる |
| 導入事例へのリンク | LPから本体サイトへ渡す唯一の導線になる |
| 会社情報へのリンク | 誰が売っているか分からないLPは、検索でも人でも信用されない |

**LPを作る前に、「これは検索で取りに行くのか、広告の受け皿か」を決める。** 両方を狙うと、どちらにも届かない。

## やらないこと

| ❌ | なぜ | ⭕️ |
|---|---|---|
| キャラクターのセリフ調の見出し | 誰かの発言に読め、BtoBでは信用を落とす | 事実を敬体で書く |
| もう◯◯で悩まない！ | 常体の話しかけ。感嘆符ではなく口調が問題 | もう◯◯で悩みません！（敬体なら可）／◯◯に時間がかかる原因は、△△にあります |
| 業界No.1・圧倒的シェア | 根拠の注記がなければ景品表示法の観点でも危うい | 調査会社名・調査期間・調査対象を注記する |
| お問い合わせ（CTA1種類のみ） | 検討段階の違う人を1つに押し込んでいる | 資料ダウンロードと相談を分ける |
| フォーム前に案内文なし | 何が起きるか分からず離脱する | 分量・費用・入力の手間・その後を書く |
| 長い1文の導入の流れ | 読まれない | ステップを3〜5個の名詞に分ける |
| 略語を並べた見出し | 読めない | 略語は1見出しに1つまで |
| 感嘆符の連打（！！ ／ ！?） | 声が大きすぎる | 感嘆符は1見出しに1つまで |
