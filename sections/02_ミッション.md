# ミッション・ビジョン・バリュー

理念を掲げるページ。**言葉を置くだけで終わらせず、必ず説明文を付ける**のがこのセクションの要点。
「〜な社会を目指します」で終わると、何もしていないように読める。

---

## このセクションに書くこと

| 要素 | 必須 | 中身 |
|---|---|---|
| 理念の言葉 | ◎ | 短く、句点で切る。10〜20字 |
| 何によって実現するか | ◎ | 手段＝事業・製品・技術。ここが抜けると空文になる |
| なぜそれをやるのか | ◎ | 問題意識・社会の状況 |
| 実現された状態 | ○ | 読み手が想像できる情景を1文 |
| バリューの説明 | ○ | 各バリューに3〜4文。言葉だけ並べない |
| バリュー同士の関係 | △ | 3つある理由。ここを書くと一気に説得力が出る |

---

## 型

### ミッション本文の型
```
1文目：ミッションの言葉そのもの
2文目：それを何によって実現するか（手段）
3文目〜：なぜそれをやるのか（問題意識・社会の状況）
```

### バリューの型
```
バリュー名（体言止め or 勧誘形）
 → 前提となる状況（1文）
 → だからどう行動するか（1〜2文）
 → それで何が起きるか（1文）
```

## 事例

### freee（[ミッション](https://corp.freee.co.jp/mission/)）

> スモールビジネスを、世界の主役に。

> freeeは「スモールビジネスを、世界の主役に。」をミッションに掲げ、統合型経営プラットフォームを開発・提供し、だれもが自由に自然体で経営できる環境をつくっていきます。

> 起業やビジネスを育てていくことを、もっと魅力的で気軽な行為に。個人事業や中小企業などのスモールビジネスに携わるすべての人が、じぶんらしく自信をもって経営できるように。

**効いている点**
- 1文の中に「ミッション語 → 手段（統合型経営プラットフォーム） → 実現される状態（自由に自然体で経営できる環境）」が収まっている。
- 動詞が「つくっていきます」。押し付けがない。
- 3文目は体言止めの連続で、リズムを変えている。理念文では有効。

### SmartHR（[私たちについて](https://smarthr.co.jp/about/)）

> well-working
> 労働にまつわる社会課題をなくし、誰もがその人らしく働ける社会をつくる。

> 働くこと。それは人生の多くの時間を使い、自分や他者に大きな影響を与える、生きていく上でとても大切なものだと考えます。
> だからこそ、誰もがその人らしく働ける社会であってほしい。だからこそ、私たちは、労働にまつわる複雑な社会課題を解決していきたい。
> 私たちは、誰もが心地よく、健康に、そして幸せに働ける社会を目指し、テクノロジーと創意工夫で、日本の労働を一歩ずつアップデートしていきます。

**構造**：定義（働くこととは何か） → だからこそ（2回反復） → 手段と姿勢
**効いている点**
- 「働くこと。」と体言で切ってから説明に入る。**主題を先に置く**書き出しは、理念文で最も汎用性が高い。
- 「だからこそ」を2回続けて、願い（社会がこうあってほしい）と決意（だから自分たちがやる）を分けている。
- 「一歩ずつ」で規模を誇張していない。

### SmartHR バリュー（[私たちについて](https://smarthr.co.jp/about/)）

> **まずやってみる人がカッコイイ**
> どの選択肢が正解かなんて誰にもわからない。だから光の速さでまず動こう。試行錯誤を重ねて正解にしていこう。前のめりな失敗は、必ず次の正解につながっていく。

> **人が欲しいものを超えよう**
> 世の中は絶えず変化している。「こんなものだろう」という思い込みを捨て、現状を疑おう。そして真の課題を見つけ、人が欲しいものを超えていこう。

> この3つのバリューは、単体で成立するものではありません。闇雲にまずやってみるのではなく、「人が欲しいものを超えられる」と思ったことに対して、必要以上に時間をかけず「まずやってみよう」という考え方です。

**効いている点**
- バリュー本文だけ常体（だ・である／勧誘形）にして、地の文の敬体と切り替えている。**引用箱として機能させる**手法。
- 各バリューが「前提 → 行動 → 結果」の3段で揃っている。
- **3つの関係性をわざわざ説明している。** バリューが空文にならない最大の理由がこれ。

### サイボウズ（[企業理念](https://cybozu.co.jp/company/philosophy/)）

> チームワークあふれる社会を創る

> サイボウズの存在意義（Purpose）は、「チームワークあふれる社会を創る」です。私たちの考えるチームワークとは、チームのメンバーが共通の理想に向かって役割分担しながら協働し、チームの生産性と働く人の幸福度が高い状態にあること。それを叶えるためには、チーム内での情報共有が欠かせません。

> kintone、Garoon、サイボウズ Office、メールワイズなど、サイボウズがこれまで世に送り出してきた製品はすべて、この情報共有にかける想いから生まれました。

> サイボウズは企業理念を大切にするからこそ、言葉や表現を固定するのではなく、そのあり方について全員で議論を重ねています。

**効いている点**
- **「私たちの考える◯◯とは」で自社定義を明示している。** 「チームワーク」のような多義語を使うときの必須の一手。
- 抽象語（チームワーク）→ 中間概念（情報共有）→ 具体（製品名の列挙）と、3段で降りている。**抽象を具体に着地させる手本。**
- 最後に「理念は更新する」と書いている。理念ページで珍しく、誠実さが伝わる。

### ナイル（[ミッション/ビジョンとバリュー](https://nyle.co.jp/company/philosophy/)）

> ミッション：幸せを、後世に。
> ビジョン：デジタル革命で社会を良くする事業家集団
> バリュー：全員、事業家／楽しんでいこう／戦う友を助ける

**効いている点**：バリューが命令形ではなく、体言止めと勧誘形。社内向けの言葉をそのまま外に出しても嫌味にならない。

### Speee（[企業情報](https://speee.jp/about/)）

> 解き尽くす。未来を引きよせる。

**効いている点**：動詞2つの言い切り。名詞句で終わらせないことで姿勢が出る。

### グッドパッチ（[Vision, Mission & Values](https://goodpatch.com/ja/company/vision-mission-values)）

**Vision**
> ハートを揺さぶる デザインで 世界を前進させる

> 2007年、iPhoneが発売されてから、私たちの世界は大きく変わりました。機能やロジックを超えて「これがいい」と感情を動かすことができるプロダクトを作る力が、今求められています。

**Mission**
> デザインの力を 証明する

> 日本におけるデザインとは表層の装飾と捉えられており、デザイナーがビジネスの現場で事業に貢献する機会は多くありません。デザイナー自身も領域を広げ、ビジネスの現場に入っていくことは少ない。故に、デザインへの投資額、デザイナーの地位は上がりにくいのです。

**Core Value 01：Inspire With Why**
> 人の心を動かすためには、共感できるWhyが大切だ。なぜ、いま目の前にある仕事に取り組んでいるのか？目的は？信念は？意義は？ストーリーは？文脈によって変化するWhyを常に問い続け言語化し、チームに共有しよう。

**効いている点**
- **ビジョンの説明を「2007年、iPhoneが発売されてから」という年号と事実から始めている。** 理念文を抽象で始めない手本。
- ミッションの説明が**現状の問題の記述に徹している**。「デザイナーの地位は上がりにくいのです」まで踏み込んで、自社の願望ではなく業界の構造を書いている。
- 「故に」で因果を明示している。理念文でつながりが曖昧になりがちな箇所を、接続詞1つで締めている。
- バリューが**問いの連打**（目的は？信念は？意義は？）を含む。リズムが変わり、読み手が自分に問い直す形になる。

### マネーフォワード（[ミッション](https://corp.moneyforward.com/aboutus/mission/)）

**MISSION**
> お金を前へ。人生をもっと前へ。

> 「お金」は、人生においてツールでしかありません。しかし「お金」とは、自身と家族の身を守るため、また夢を実現するために必要不可欠な存在でもあります。私たちは「お金と前向きに向き合い、可能性を広げることができる」サービスを提供することにより、ユーザーの人生を飛躍的に豊かにすることで、より良い社会創りに貢献していきます。

**VISION**
> すべての人の、「お金のプラットフォーム」になる。

**VALUE：Fairness**
> 私たちは、ユーザー、社員、株主、社会などのすべてのステークホルダーに対してフェアに誠実に向き合い、オープンマインドであることを誓います。

**効いている点**
- **「〜でしかありません。しかし〜でもあります。」** と、1つの対象を2面から定義してから本題に入っている。理念文の書き出しとして応用範囲が広い。
- バリューで対象を具体的に列挙している（ユーザー、社員、株主、社会）。「ステークホルダー」だけで済ませていない。

### ニジボックス（[トップ](https://nijibox.jp/)）

> 全ての企業のサービスを成長させる

**効いている点**：ミッションを目的語つきの1文にしている。「成長」だけ、「支援」だけの名詞句で終わらせていない。

### 才流（[会社紹介](https://sairu.co.jp/)）

> 私たちは一人ひとりがかけがえのない広大な才能を持っていると信じています。

> **ホワイトエンジン**：倫理的に恥じることがなく、正しいと思えることを正しいと思えるやり方でやること

**効いている点**：造語（ホワイトエンジン）に、必ず定義文を付けている。造語を置くなら定義はセット。

## 使える言い回し

| 場面 | 表現 |
|---|---|
| 定義する | 私たちの考える◯◯とは、〜です／〜を◯◯と呼んでいます |
| 手段を示す | 〜を開発・提供し、〜をつくっていきます／〜と創意工夫で、〜していきます |
| 願いと決意を分ける | だからこそ、〜であってほしい。だからこそ、私たちは〜したい |
| 規模を誇張しない | 一歩ずつ／着実に／続けていきます |
| 具体に降ろす | 〜など、これまで世に送り出してきた製品はすべて、〜から生まれました |
| 更新を認める | 言葉や表現を固定するのではなく、〜議論を重ねています |

---

## やらないこと

| ❌ | なぜ | ⭕️ |
|---|---|---|
| ◯◯な社会を目指します（で終わる） | 手段がないと空文 | ◯◯な社会を目指し、△△を開発・提供しています |
| 我々のバリューは3つです（列挙だけ） | 言葉が独り歩きする | 各バリューに3〜4文の説明を付ける |
| シナジーを最大化し、新たな価値を創造する | 全部カタカナ抽象語 | 2つの事業のデータを合わせて、◯◯を提供します |
| 世界を変える／社会を革新する | 検証も想像もできない | 誰の、何が、どう変わるかを1文で書く |
| （造語だけ置く） | 読み手に伝わらない | 造語には必ず定義文を付ける |
