# 代表メッセージ

「代表挨拶」「トップメッセージ」「CEOメッセージ」。
**読み手が誰かで、書き方が完全に変わる。** まず宛先を決めてから書く。

---

## 2つの型を混ぜない

| 型 | 宛先 | 書き出し | 中身 |
|---|---|---|---|
| **顧客・採用向け** | サイト訪問者、求職者 | 目指している状態から入る | 創業経緯、原体験、いまの事業 |
| **株主向け（IR）** | 株主、投資家 | 謝辞から入る | 業績、構造改革、次期の方針 |

コーポレートサイトのトップから辿る代表挨拶は前者。IRページ配下は後者。
**前者に「平素より格別のご高配を賜り」を書くと、距離が遠くなりすぎる。**

---

## このセクションに書くこと

### 顧客・採用向けの場合

| 要素 | 必須 | 中身 |
|---|---|---|
| 目指している状態 | ◎ | 1文目。理念の言い換え |
| 創業の事実 | ◎ | いつ・誰が・何を。年号と人名を入れる |
| ビジョンと、その背景の課題 | ◎ | なぜそれを掲げるか |
| 原体験 | ○ | 感情語を**1回だけ**使う。多用すると軽くなる |
| いまの事業 | ◎ | 事業名を列挙して具体化する。ここで抽象を降ろす |
| 締め | ◎ | 誓約ではなく、続ける意思 |

---

## 型

```
第1段落：目指している状態 ＋ 創業の事実（いつ・誰が・何を）
第2段落：掲げているビジョンと、その背景にある課題。原体験を1文
第3段落：課題に対して、いま何の事業をやっているか（事業名を列挙）
第4段落：締め。読み手に何も要求しない
```

---

## 事例

### ウィルゲート（[代表挨拶](https://www.willgate.co.jp/company/greeting/)）— 顧客・採用向けの手本

**第1段落**
> 株式会社ウィルゲートは、一人ひとりが『will』の実現に向けて前向きに挑戦できる社会、挑戦することが周りの人々へと波及していく世界をつくることを目指しています。当社は2006年当時学生だった私と専務取締役 吉岡が立ち上げました。

**第2段落**
> このビジョンの背景には、経済活性化の原動力となるベンチャー企業が、収益性の向上や売上の拡大に苦戦をし、人材や事業に十分な投資ができず、本当に取り組みたい事業に注力できないという課題があります。私たちも創業当時は経営の選択肢が少なく思うように挑戦できない悔しさを、原体験としても強く感じてきました。

**第3段落**
> 「M&A事業」では、ベンチャー・ITに強い着手金無料のM&A仲介支援サービスを展開。「コンテンツマーケティング事業」では、SEOを中心としたWebマーケティングのコンサルティング・コンテンツ制作・SEOの内製化を支援するSaaSの提供。

**第4段落**
> 私たちは企業活動を通してユーザー・クライアント・社員・社会に対して、『will』の実現に立ちはだかる課題へ共に向き合い、時に『will』を見出す支援をすることで、その実現に貢献していきます。

**効いている点**
- 理念（『will』）を掲げたあと、**第3段落で事業名と提供内容まで降りている**。抽象で終わっていない。
- 「悔しさ」という感情語を**1回だけ**使い、それ以外は事実で書いている。
- **読み手に何も要求していない。**「ぜひご相談ください」で締めていない。ここが品位を保っている。
- 「支援してきました」と過去形で実績を、「貢献していきます」と未来形で意思を、書き分けている。

### ホットリンク（[代表メッセージ](https://www.hottolink.co.jp/company/message/)）— 株主向けの型

> 株主の皆様におかれましては、平素よりホットリンクグループの事業活動に対し、格別のご理解とご支援を賜り、心より御礼申しあげます。

> この1年は、成長を急ぐのではなく、次の飛躍に向けた土台づくりに注力した期間であったと捉えています。

> この1年は、「クチコミ係長」の提供停止をはじめ、既存事業を厳しく見直し、痛みを伴う選択と集中を進めてきた期間でもあります。いずれも次の成長フェーズに進むために不可欠な決断であったと考えています。

> 不確実性の高い時代においても、私たちは磨き上げた技術と人の創造性を価値の源泉とし、社会に必要とされ続ける企業を目指します。

**効いている点**
- **撤退したサービス名を実名で書いている。** 都合の悪い事実を書くと、他の記述の信頼度が上がる。
- 「成長を急ぐのではなく」と、やらなかったことを明示している。
- 「〜と捉えています」「〜と考えています」で、事実と解釈を分けている。断定しすぎない。

### 才流（[会社紹介](https://sairu.co.jp/)）

> 日々の仕事の時間が、睡眠や家族、趣味と同じぐらい良いものになることを目指しながら、会社を運営しています。

**効いている点**：仕事を人生の他の時間と並べて相対化している。「働きがい」と書くより具体的で、読み手が自分ごとにしやすい。

## 使える言い回し

| 場面 | 表現 |
|---|---|
| 目指す状態を書く | 〜な社会、〜な世界をつくることを目指しています |
| 創業を書く | 当社は◯年、〜だった私と△△が立ち上げました |
| 背景の課題を書く | このビジョンの背景には、〜という課題があります |
| 原体験を書く | 私たちも創業当時は〜を、原体験として強く感じてきました |
| 事業に降ろす | 「◯◯事業」では、〜を展開。「△△事業」では、〜を提供 |
| 実績と意思を分ける | 〜してきました（過去形）／〜していきます（未来形） |
| 解釈だと示す | 〜であったと捉えています／〜と考えています |
| 撤退を書く | 〜の提供停止をはじめ、既存事業を厳しく見直しました |

## やらないこと

| ❌ | なぜ | ⭕️ |
|---|---|---|
| 皆様のご期待に応えられるよう、社員一同精進してまいります | 定型で情報量ゼロ | 〜の改善を、これからも続けていきます |
| ぜひ一度ご相談ください | 挨拶文で営業しない | （締めは意思表明で終える） |
| 弊社は業界のリーディングカンパニーとして | 検証できない自称 | 設立から◯年、◯社の支援をしてきました |
| 熱い想いを胸に、情熱を持って、全力で | 感情語の多用は軽くなる | 感情語は文章全体で1回まで |
| 平素より格別のご高配を賜り（顧客向けページで） | 株主向けの言い回し | 顧客向けは目指す状態から書き出す |
