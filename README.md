# ai-site-writing

Claude Codeでサイトの文面を書くときに参照する、日本語ライティングの参考集。
**セクション（面）ごとに、「何を書くか」と「他社が実際にどう書いているか」がセットで並んでいる。**

**公開サイト**：https://hiroho-t.github.io/ai-site-writing/

## 構成

### セクション別の事例 — `sections/`

| ファイル | 面 |
|---|---|
| [00_一覧.md](sections/00_一覧.md) | 索引 |
| [01_会社紹介.md](sections/01_会社紹介.md) | 私たちについて／About |
| [02_ミッション.md](sections/02_ミッション.md) | ミッション・ビジョン・バリュー |
| [03_代表メッセージ.md](sections/03_代表メッセージ.md) | 代表挨拶／トップメッセージ |
| [04_サービス紹介.md](sections/04_サービス紹介.md) | サービスページのリードとメニュー |
| [05_課題提起.md](sections/05_課題提起.md) | 導入部の課題提起 |
| [06_実績と数字.md](sections/06_実績と数字.md) | 導入社数・支援実績 |
| [07_採用.md](sections/07_採用.md) | 採用ページ |
| [08_よくある質問.md](sections/08_よくある質問.md) | FAQ |
| [09_お問い合わせ導線.md](sections/09_お問い合わせ導線.md) | CTA |

各ファイルは同じ構成。**このセクションに書くこと** → **型** → **事例** → **使える言い回し** → **やらないこと**。

### ルール — `rules/`

| ファイル | 中身 | いつ読むか |
|---|---|---|
| [02_文章の組み立て.md](rules/02_文章の組み立て.md) | 上から目線と抽象の原因、敬語の距離感、文の作り方 | 書く前 |
| [03_共通NG.md](rules/03_共通NG.md) | 全セクション共通のNG→OK | 書いたあと |
| [01_表記ルール.md](rules/01_表記ルール.md) | 漢字ひらがな・カタカナ・数字・記号 | 書いたあと |

[出典.md](出典.md) に、参照した公開ガイドラインと企業サイトの一覧。

## 使い方

案件ごとに、必要なファイルをClaude Codeに読み込ませる。スキルとしては登録していない。
案件によって必要な面が変わるため、そのつど選んで渡す前提。

```
sections/01_会社紹介.md と rules/03_共通NG.md を読んでから、会社紹介の文面を書いて
```

## 収集の方針

- 他社の文面は短い引用＋出典URLにとどめる。全文を転記しない。
- 流用するのは文そのものではなく、抽出した【型】と【言い回し】。
- コーポレート文体と、記事・メディア文体（創業手帳／NewsPicks／PIVOT／LIGブログ）は混ぜない。
