# ai-site-writing

Claude Codeでサイトの文面を書くときに参照する、日本語ライティングの参考集。

**公開サイト**：https://hiroho-t.github.io/ai-site-writing/

## ファイル

| ファイル | 中身 | いつ使うか |
|---|---|---|
| [01_表記ルール.md](01_表記ルール.md) | 文体・呼称・漢字ひらがな・カタカナ・数字・記号 | 書いたあとの検算 |
| [02_文章の組み立て.md](02_文章の組み立て.md) | 上から目線と抽象の原因、敬語の距離感、文の作り方 | 書く前に読む |
| [03_文例と型.md](03_文例と型.md) | 共通NG→OK ＋ 面別の型と実例 | 面ごとに型を選ぶ |
| [04_出典.md](04_出典.md) | 参照した公開ガイドラインと企業サイト | 根拠をたどるとき |

## 使い方

案件ごとに、必要なファイルをClaude Codeに読み込ませる。スキルとしては登録していない。
案件によって必要な面（会社紹介・サービス紹介・採用など）が変わるため、そのつど選んで渡す前提。

```
01_表記ルール.md と 03_文例と型.md を読んでから、会社紹介の文面を書いて
```

## 前提

既存スキル `concrete-writing` が「抽象的な書き方（北極星・主語欠落・自社/御社の混同）」を担当している。
本リポジトリはそこと重複させず、**敬語の距離感・表記統一・面ごとの構文**を担当する。

## 収集の方針

- 他社の文面は短い引用＋出典URLにとどめる。全文を転記しない。
- 流用するのは文そのものではなく、抽出した【型】。
- コーポレート文体（ウィルゲート／PLAN-B／Speee／ナイル／freee）と、記事・メディア文体（創業手帳／NewsPicks／PIVOT／LIGブログ）は混ぜない。

出典の一覧は [04_出典.md](04_出典.md) を参照。
