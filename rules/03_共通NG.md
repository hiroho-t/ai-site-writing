# 共通NG→OK

どのセクションを書くときにも共通する、やってはいけない書き方。

セクション別の事例集には「良い文」しか載っていない。
他社サイトに載っていない書き方は、事例をいくら読んでも学べないので、ここに明示する。
**文面を書き終えたら、必ずこのページで検算する。**

## 1. 上から目線を消す

上から目線は5つの型に分解できる。書いたあと、この5つで検算する。

### ① 動詞が「教える側」に立っている

| ❌ | ⭕️ |
|---|---|
| 御社にお教えします | 具体的な手順をお伝えします |
| ノウハウを伝授します | ノウハウをご紹介します |
| 正しいSEOをご指導します | SEOの進め方を解説します |
| アドバイスさせていただきます | ご提案します |

教える・伝授する・指導する・啓蒙する・レクチャーする、は使わない。
伝える・紹介する・解説する・提案する・共有する、に置き換える。

### ② 自社が「与える側」に立つ構図

| ❌ | ⭕️ |
|---|---|
| 弊社が御社の課題を解決します | サイト設計から運用までを担当します |
| 私たちが成功に導きます | 公開後6か月間、改善を続けます |
| 貴社を成長させます | 問い合わせ件数を増やすための施策を実行します |

主語を「自社」から「行う作業」に移すと、自然に消える。
成功に導く・引き上げる・救う・変革する、は避ける。

### ③ 命令・当為で終わっている

| ❌ | ⭕️ |
|---|---|
| 〜すべきです | 〜が有効です |
| 〜しなければなりません | 〜が必要になります／〜をおすすめします |
| 必ず〜してください | 〜していただくと、◯◯できます |
| 〜は間違いです | 〜だと、◯◯が起きます |

読み手に選択の余地を残す。ただし手順の説明では「〜してください」でよい。
禁じているのは、判断を押し付ける「べき」であって、丁寧な指示ではない。

### ④ 読み手の無知を前提にしている

| ❌ | ⭕️ |
|---|---|
| 意外と知られていませんが | （まるごと削除） |
| ご存じない方も多いのですが | （まるごと削除） |
| 実は多くの企業が間違えています | 対応が漏れやすい箇所です |
| 基本的なことですが | （まるごと削除） |
| ここを見落としている企業がほとんどです | 見落とされやすい箇所です |

「主語を企業一般にして、責める対象を消す」と直る。

### ⑤ 過剰な謙譲で、かえって慇懃無礼

| ❌ | ⭕️ |
|---|---|
| 〜させていただいております | 〜しています |
| ご覧いただけますと幸いです | ご覧ください |
| お力添えさせていただきます | 一緒に進めます |

謙譲を重ねるほど、相手との距離が遠くなる。距離が遠い＝丁寧、ではない。

## 2. 空約束を書かない

| ❌ | ⭕️ |
|---|---|
| 必ず成果が出ます | 3か月ごとに効果を測定し、施策を組み替えます |
| どんな課題にも対応します | BtoBサイトの集客と、その後の商談化まで対応します |
| 業界最安値 | 月額15万円から |
| 圧倒的な実績 | 導入実績125社（2026年8月時点） |
| 徹底的にサポートします | 専任担当が週1回の定例で進捗を確認します |

数字が出せないなら、その一文を消す。あいまいな数字を書かない。

## 3. 比喩の扱い

理念・ミッション文では比喩が機能することがある（PLAN-Bの「両輪」など、実際に大手も使う）。
一方、**サービス説明・記事本文・提案書では比喩を使わない**。読み手が意味を考える一拍が発生する。

| 面 | 比喩 |
|---|---|
| ミッション・ビジョン・代表メッセージ | 1つまで許容 |
| 会社紹介・サービス紹介・記事本文・FAQ | 使わない |

避ける語：北極星、羅針盤、両輪、土台、エンジン、ハブ、伴走、寄り添う、旗を立てる、地図を描く、ワンストップ、シナジー
※「伴走」「ワンストップ」は業界で定着しているが、必ず「何をするのか」を後ろに1文足す。
